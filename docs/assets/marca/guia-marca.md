# MesaTech Cloud — guía de marca (imágenes)

Identidad canónica: isotipo hexagonal de `entregables/presentacion/img/marca/logo.png`  
(nube facetada + ticket con punto). Paleta del deck: teal / aqua.

Tagline: Soporte tecnológico centralizado.

---

## 1. Paleta (cerrada)

| Uso | Hex | Qué es / qué no es |
| --- | --- | --- |
| Primario | `#0F4C5C` | Teal verde (petrol). Hexágono y objetos. No es navy azul. |
| Primario oscuro | `#0A3843` / `#071E24` | Estudio / vacío detrás. |
| Acento | `#2EC4B6` | Aqua verde. Punto del ticket y luz. No es sky `#0EA5E9`. |
| Acento suave | `#E8FAF6` | Mint. Nube, tickets, vidrio. |
| Texto (si hay) | `#12353C` | Ink del deck. |
| Fondo app / slides claras | `#F7FBFA` | Sand. Las fotos van en teal oscuro. |

Prohibido en este kit: navy `#1E3A5F`, sky `#0EA5E9`, naranja, púrpura.

---

## 2. Isotipo que se repite

Hexágono teal + nube mint de trazo facetado + ticket mint con punto aqua.  
En las fotos **no** se escribe MESATECH. Variante blanca: `logo-white.png`.

---

## 3. Estilo visual: still-life 3D de producto

| Qué es | Qué no es |
| --- | --- |
| Render 3D en estudio teal | Foto de oficinas o personas |
| Un objeto o una escena corta | Infografía, HUD, logo repetido en el cierre |
| Cámara a la altura de los ojos, 16:9 | Picado dramático |
| Materiales: teal mate + mint + aqua | Metal naranja, niebla de película |
| Izquierda vacía para el título del slide | Imagen llena |

**Luz:** fuente suave arriba-izquierda + filo aqua a la derecha.

**Piso:** teal oscuro, reflejo débil.

---

## 4. Cómo se usa en el slide

1. Imagen a 16:9 de fondo.
2. Título a la **izquierda**, sobre el vacío teal.
3. No agregar más copy sobre la foto.
